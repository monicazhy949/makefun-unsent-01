One line, addressed to one person and no one else. It opens on Daniel, the best friend since third grade, and folds the addressee into the sentence itself: he married Emily on June 14th, and the sender still keeps the 214-word wedding toast in her notes — the toast where she tells everyone she loved him first. It was written for a wedding that already happened and never delivered, so the confession only makes sense spoken to Daniel, and it only hurts because it is too late to say it. Running `python3 main.py` prints the confession and also writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
